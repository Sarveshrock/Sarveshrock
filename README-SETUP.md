# README-SETUP

## Layout (matches the dashboard reference)

Banner illustration → link buttons → live stat tiles → contribution terminal + languages → tech stack (official icons + chips) → projects → experience → achievements → AI core / terminal / status → footer.

## Deploy

1. Copy `README.md`, `assets/`, `scripts/` and `.github/` into the root of the `Sarveshrock/Sarveshrock` repo and push to `main`.
2. In the repo go to **Settings → Actions → General → Workflow permissions** and choose **Read and write permissions** (needed so the workflow can commit refreshed stats).
3. Run the workflow once: **Actions → Update profile stats → Run workflow**.
4. Set your GitHub bio at github.com/settings/profile. Suggested: "AI/ML Engineer at Infosys. Computer Vision, Generative AI, LLMs."

## What updates automatically

| Element | Source | Refresh |
|---|---|---|
| Stat tiles (repositories, contributions in last year, followers, following) | GitHub API + public contribution calendar via `update_stats.py` | daily GitHub Action |
| Contribution heatmap | public contribution calendar | daily |
| Most used languages | GitHub languages API, non-fork public repos, by code size | daily |

All three are SVGs in `assets/dynamic/`. If GitHub is unreachable the script exits without touching the existing files, so you never get partial numbers.

Everything else is static and regenerated by `python scripts/optional-generation-scripts/build_assets.py`.

## Maintenance

- New job, project or achievement: edit the data blocks in `build_assets.py` (`PROJECTS`, `ACH`, `TECH`, `experience()`), run it, commit.
- When a resume project gets a public repo, wrap its card image in `<a href="https://github.com/Sarveshrock/<repo>">` and change its source tag.
- Footer year lives in `footer()`.

## Fact provenance

- Resume: roles, dates, education, skills, the 7 project descriptions, achievements. Project cards say "SOURCE: RESUME · NO PUBLIC REPO" and have no links.
- GitHub: UnmaskAI (description "SEED HACKATHON Submission", language Python); all numbers and language shares are computed live.
- Your own brief (not found in resume or GitHub): tagline, "Open Source Enthusiast", "currently building" list, quote in the stats strip. Remove them if you want an evidence-only page.
- Not shown: phone number, unverified repos, AURA, AI-Contract.
- Location is omitted (not set on GitHub).

## Notes

- The reference image is a design mock; its numbers (73 repos, 98 followers, stars, etc.) and pinned repos are placeholders and are not used.
- Projects are in a single column so the text stays readable on phones. For a 2-column desktop grid, put two `<img>` tags in an HTML `<table>` row, but card text will shrink on mobile.
- The script-style name in the banner uses a cursive font stack (Segoe Script, Snell Roundhand, Brush Script MT). SVGs shown through `<img>` cannot load web fonts, so the exact face depends on the viewer's OS.
- Repo hygiene is yours: NASA, Max-num and Intern have unprofessional descriptions.
